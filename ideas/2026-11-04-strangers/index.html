    Fix it

    Add a cooldown so brand-new releases can't reach your machine.

    # npm (>=11.5) — wait 7 days before installing a release
npm config set minimum-release-age 10080

# pnpm (>=10.16)
pnpm config set minimumReleaseAge 10080

# bun
bun pm config set minimumReleaseAge 10080

# and stop arbitrary install scripts entirely
npm config set ignore-scripts true
    THE 5 PACKAGES TO DROP FIRST
    • 1. tar-fs — install script + 3 maintainers, replace with native tar
    • 2. node-gyp — only needed for native rebuilds, pin or vendor it
    • 3. sharp — 1-day-old release, pin exact version or use @squoosh
    • 4. esbuild — downloads a binary at install, use ignore-scripts + manual bin
    • 5. picomatch — transitive-only, dedupe to one copy
